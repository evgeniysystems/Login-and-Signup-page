# Solara Auth UI

A modern, responsive, and interactive Login and Signup interface built with pure vanilla web technologies.

## 🚀 Features
* **Smooth Animations:** CSS transitions and dynamic sliding panels without reloading the page.
* **Fully Responsive:** Adapts flawlessly to desktop, tablet, and mobile screens using Viewport units and media queries.
* **Interactive UI:** Password visibility toggle (eye icon) and tactile active states for buttons.
* **UX Optimized:** Disabled default drag-and-drop and text selection for a native application feel.

## 🛠️ Tech Stack
* **HTML5:** Semantic structure.
* **CSS3:** Flexbox, Custom properties, Viewport-driven UI.
* **Vanilla JavaScript:** DOM manipulation, Event Listeners.
